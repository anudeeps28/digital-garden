# Metcalfe's Law

## Idea
A network's value grows roughly with the square of its number of users, so a slightly bigger network can be much more valuable than a smaller rival, which pushes markets toward winner-take-all.

## Definition
With *n* users there are about *n²/2* possible connections, so doubling the users roughly quadruples the possible connections. Every new user of a messaging app, marketplace or social platform makes it more useful to everyone already there. That is why users go where users already are, and why the leader's advantage grows. Note that this growth is **quadratic, not exponential**, a common misstatement. The dynamic is a reinforcing loop: more users bring more value, which brings more users. For a challenger, it means that matching features is not enough. You need a niche where your network is the biggest, or a way to borrow an existing network.

## Source
Attributed to Robert Metcalfe, co-inventor of Ethernet, around 1980 (originally about compatible communicating devices). George Gilder named and popularized it in 1993. Later critics (Briscoe, Odlyzko and Tilly, 2006) argued that real value grows closer to *n log n*, because most connections are rarely used. Encountered in a video on inequality alongside the [[Matthew Effect]].

## Compass

**Roots** — *where this comes from*
It is the network-economics version of a [[Reinforcing Feedback Loop]], and the mechanism that makes [[Success to the Successful]] especially strong for platforms.

**Paths** — *where this leads*
It predicts the [[Power Law Distribution]] of platform market share and explains why [[The Flywheel Concept]] in a network business is about user density before features.

**Neighbors** — *what lives nearby*
The [[Matthew Effect]] is the same rich-get-richer dynamic in individuals and attention. [[Unit Economics]] is its counterweight on the cost side: network value per user may rise, but so can the cost of serving each user.

**Clash** — *what pushes against this*
Value per connection is not uniform. Most users only care about a few contacts, which is why *n log n* fits better and why small, dense networks can beat large, sparse ones. Network effects also run in reverse: when users leave, value falls quadratically too.
