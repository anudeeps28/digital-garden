# C#

## Idea
C# is a statically-typed, object-oriented programming language developed by Microsoft.

## Definition
C# (pronounced "C-sharp") is a general-purpose, high-level programming language that runs on the [[.NET 8]] runtime. It combines the power of C/C++ with the productivity of languages like Java, offering strong typing, garbage collection, and first-class support for modern patterns like [[Async Await in CSharp]], [[Interfaces in CSharp]], and [[Dependency Injection]].

## Source
Anders Hejlsberg, Microsoft; first released with .NET Framework in 2000. Evolved continuously as part of the .NET ecosystem, with major releases tracked alongside .NET versions.

## Compass

**Roots** — *where this comes from*
[[.NET 8]] is the runtime and framework that executes C# code, providing the foundation for the language. [[Clean Architecture]] is the architectural pattern used to structure C# projects, establishing how code is organized and designed.

**Paths** — *where this leads*
[[Interfaces in CSharp]] enable contract-based design, a core principle in C# development. [[Async Await in CSharp]] provides C#'s approach to asynchronous programming. [[Namespaces in CSharp]] show how C# organizes code into logical groups. C#'s strong type system supports [[Unit Tests]], making testable code design natural.

**Neighbors** — *what lives nearby*
[[Java]] is also a statically-typed, object-oriented language running on a managed runtime, offering similar design principles. [[TypeScript]] is another statically-typed language with similar syntax conventions.

**Clash** — *what pushes against this*
[[Python]] is dynamically-typed and interpreted with a very different design philosophy that prioritizes flexibility over strict typing. [[JavaScript]] is loosely-typed and prototype-based rather than class-based, representing a fundamentally different approach to object orientation.
